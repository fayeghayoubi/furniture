# Furniture Landing Page

A responsive furniture store landing page built primarily to practice and demonstrate proficiency with **Tailwind CSS**, combined with JavaScript for interactive UI behavior.

## 🎯 Purpose

This project was built as a personal practice project to strengthen Tailwind CSS skills — implementing a fully responsive layout entirely with utility classes, a custom extended theme, and modern layout techniques, alongside JavaScript for interactivity (mobile navigation toggle, slider, etc.).

## 🧰 Tech Stack

- **HTML5**
- **Tailwind CSS** — utility-first styling (compiled to `src/output.css`)
- **JavaScript** — Vanilla JS + jQuery
- **Swiper.js** — carousel / slider
- **Font Awesome 5** — icons

## ✨ Features

- Fully responsive layout (mobile, tablet, desktop)
- Sticky header with animated mobile navigation toggle
- Hero section with call-to-action
- Brand logo showcase strip
- Product grid section
- About section
- Newsletter signup form
- Smooth in-page anchor navigation
- Custom Tailwind theme (extended colors, spacing, and border-radius utilities)

## 📁 Project Structure

```
furniture/
├── public/
│   ├── images/          # Site images, logos, product photos
│   └── js/               # Custom JavaScript and jQuery
├── src/
│   ├── output.css        # Compiled Tailwind CSS
│   └── vendor/             # Third-party libraries (FontAwesome, Swiper)
└── index.html
```

## 🚀 Getting Started

No build step is required to view the site — the Tailwind CSS output is already compiled into `src/output.css`. Just open `index.html` in a browser, or serve the folder with a local development server (e.g., the **Live Server** extension in VS Code) for the best experience.

## 📚 What I Practiced

- Structuring a complete real-world layout entirely with Tailwind utility classes
- Extending Tailwind's default theme (custom color palette, spacing scale, border radius)
- Responsive design using Tailwind's breakpoint prefixes
- DOM manipulation with vanilla JavaScript (mobile menu toggle)
- Integrating a third-party slider library (Swiper.js)
